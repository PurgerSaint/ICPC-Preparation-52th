# C.小月的对局
## 题目详情
$\hspace{15pt}$Alice 和 Bob 正在进行一场纸牌对局。他们各有 $n$ 张牌，每张牌上都写着一个正整数。Alice 的牌面数字为 $\{a_1,a_2,\dots,a_n\}$，Bob 的牌面数字为 $\{b_1,b_2,\dots,b_n\}$。  
$\hspace{15pt}$每轮对局按以下顺序进行：  
$\hspace{23pt}\bullet\,$Alice 从自己剩余的牌中选择一张打出，记牌面数字为 $x$；  
$\hspace{23pt}\bullet\,$Bob 在看到 Alice 本轮打出的牌后，从自己剩余的牌中选择一张打出，记牌面数字为 $y$；  
$\hspace{23pt}\bullet\,$若 $\gcd(x,y)>1$，Alice 立即获胜，对局结束；否则，将本轮打出的两张牌移出对局，它们不能再次使用。  
$\hspace{15pt}$对局持续进行，直到 Alice 获胜或双方的牌全部用完。若双方的牌均已用完，且 Alice 仍未获胜，则 Bob 获胜。  
$\hspace{15pt}$双方均采取最优策略。请判断最终的胜者。  
【名词解释】  
$\hspace{15pt}$$\gcd$：最大公约数，指两个或多个整数共有约数中最大的一个。例如，$12$ 和 $30$ 的公约数有 $1,2,3,6$，其中最大的约数是 $6$，因此记作 $\gcd(12,30)=6$。特别地，单个整数的 $\gcd$ 定义为其自身。
*intput*  
$\hspace{15pt}$第一行输入一个整数 $n\left(1\leqq n\leqq 6\right)$，表示双方各自持有的牌数。  
$\hspace{15pt}$第二行输入 $n$ 个整数 $a_1,a_2,\dots,a_n\left(1\leqq a_i\leqq 30\right)$，表示 Alice 的牌面数字。  
$\hspace{15pt}$第三行输入 $n$ 个整数 $b_1,b_2,\dots,b_n\left(1\leqq b_i\leqq 30\right)$，表示 Bob 的牌面数字。
*output*  
$\hspace{15pt}$若 Alice 获胜，输出 $\texttt{Alice}$；否则，输出 $\texttt{Bob}$。

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;
#define ios ios::sync_with_stdio(false);cin.tie(0);
#define range(a) a.begin(), a.end()

int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}

int main() {
    ios;
    vector<bool> f(31, 1);
    for (int i = 2; i <= 30; i++) {
        if (f[i]) {
            for (int j = i * 2; j <= 30; j += i)
                f[j] = 0;
        }
    }
    f[2] = 0;
    int n; cin >> n;
    int cnt_a = 0, cnt_b = 0;
    vector<int> a(n), b(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        cnt_a += f[a[i]];
    }
    for (int i = 0; i < n; i++) {
        cin >> b[i];
        cnt_a += f[b[i]];
    }
    if (cnt_b == n || cnt_a == n) {
        cout << "Bob";
        return 0;
    }
    int cnt = 0;
    for (int& i: b) {
        for (int& j: a) {
            if (gcd(i, j) > 1) {
                cnt++;
                break;
            }
        }
    }
    if (cnt == 0) cout << "Bob";
    else cout << "Alice";
    return 0;
}
```
