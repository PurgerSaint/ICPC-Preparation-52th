## 题目详情
给定一棵 $n$ 个点的带权树，结点下标从 $1$ 开始到 $n$。求树中所有异或路径的最大值。
异或路径指树上两个结点之间唯一路径上的所有边权的异或值。
*输入格式*
第一行一个整数 $n$，表示结点数。
接下来 $n-1$ 行，给出 $u,v,w$ ，分别表示树上的 $u$ 点和 $v$ 点有连边，边的权值是 $w$。
*输出格式*
一行，一个整数表示答案。
*数据范围*
$1\le n \le 10^5;0 < u,v \le n;0 \le w < 2^{31}$。
## 提交详情
- 提交时间:22:45:30 状态:AC 详细状态:`-`
> 我的初始想法是计算每个子树的异或值，即每个节点作为根节点所在子树的异或总值  
异或性质为 $a\oplus a=0, a\oplus 0=a$ ，但对于 $a\oplus b$ 无解(只能硬算)  
不能通过LCA快速计算两点路径异或和，因为会包含别的子树  
这题我没想通如何快速得到任意两结点的最大异或值，况且异或不能按数量最多、总和最大来看，他的性质就是如上两条，其他的就没了  
经*DeepSeek*指导后，我懂得了两路径的异或和怎么求了  
存在两个点`u`和`v`，设`d[u]`为自根节点`1`到当前节点`u`的路径上所有边权异或和，点`l`为`LCA(u,v)`    
那么可得到:
```md
d[u] ^ d[v]
= (1 -> l) ^ (l -> u) ^ (1 -> l) ^ (l -> v)
= 0 ^ (l -> u) ^ (l -> v)
= (l -> u) ^ (l -> v)
```
即`u`到`v`的路径异或和为`d[u] ^ d[v]`  
那么由此经*DeepSeek*指导，可得到0-1Trie  
0-1Trie本质上是对所有整数，将其以二进制字符串的形式存入字典树中  
本题由于 $0 \le w < 2^{31}$ ，故将每个权值存入字典树时，都将其拉到30位，以30位二进制字符串存入  
其存入逻辑同普通字典树，然后结构体为`int ch[2]={0}`，即每个节点仅有`0`或`1`两种节点值(二进制性质)  
但查询时却不是按普通字典树那样寻找最长公共前缀，也不是找匹配，而是去枚举他的异或对象，枚举所有权值异或和的另一个异或对象，枚举这个异或和能使其更大的值，直接构造结果    
即对于本题来说，在已知`a=dis[u]`的情况下，想要寻找一个`b`使得 $a\oplus b$ 更大，那么就从最高位(30位)开始寻找  
寻找 $a$ 每一位的相反位，这样异或值才会更大  
保存自根节点到每个节点的异或和，然后将所有异或和存入字典树中，并枚举所有异或和通过字典树寻找更大异或值

## 题目详情
You are given $n$ lowercase English strings $s_{1}, s_{2}, \dots, s_{n}$.
For each pair of integers $(i, j)$ satisfying $1 \le j \le i \le n$, define $f_{i,j}$ as the maximum possible length of the longest common prefix of exactly $j$ strings selected from the first $i$ strings. Formally,
$$f_{i,j} = \max_{T \subseteq \{1, 2, \dots, i\}, \vert{}T\vert{} = j} \vert{}\operatorname{LCP}(s_{k} \mid k \in T)\vert{}.$$
The longest common prefix of a single string is the string itself.
For each $i = 1, 2, \dots, n$ calculate
$$\sum_{j=1}^{i}(f_{i,j} \oplus j),$$
where $\oplus$ denotes the bitwise XOR operation.
*Input*
The first line contains an integer $n$ ($1 \le n \le 5 \cdot 10^{5}$), the number of strings.
Each of the next $n$ lines contains a non-empty string $s_{i}$ consisting only of lowercase English letters.
It is guaranteed that
$$\sum_{i=1}^{n} \vert{}s_{i}\vert{} \le 5 \cdot 10^{5}.$$
*Output*
Print $n$ lines.
The $i$-th line should contain one integer:
$$\sum_{j=1}^{i}(f_{i,j} \oplus j).$$

struct state {
    vector<pair<char, int>> edge;   // 子节点
    bool end = 0;                   // 是否为某个字符串的结尾
};
vector<state> node(1);              // 树本体
void insert(const string& s) {
    int u = 0;                      // 初始根节点
    for (char c: s) {
        int v = -1;
        for (auto& [c1, v1]: node[u].edge)
            if (c1 == c) {
                v = v1; break;
            }
        if (v == -1) {
            v = node.size();
            node.emplace_back();
            node[u].edge.emplace_back(c, v);
        }
        u = v;
    }
    node[u].end = 1;                // 标记结尾
}

string lcp() {
    int u = 0;  string ans = "";
    // 出现分支(多个子节点)，或提前遇到结束标识
    while (!node[u].end && node[u].edge.size() == 1) {
        auto& [c, v] = node[u].edge[0];
        ans += c;
        u = v;
    }
    return ans;
}

int find(const string& s) {
    int u = 0;                      // 根节点
    for (char c: s) {
        int v = -1;
        for (auto& [c1, v1]: node[u].edge) {
            if (c == c1) {
                v = v1; break;
            }
        }
        if (v == -1) return -1;    // 未找到
        u = v;
    }
    return u;
}

struct state {
    int ch[2] = {0};                // 异或两种结果
};
vector<state> trie(1);
void insert(const int& x) {
    int u = 0;
    for (int i = 30; i >= 0; i--) {
        int b = (x >> i) & 1;       // 获取 x 的第 i 位
        if (trie[u].ch[b] == 0) {
            trie[u].ch[b] = trie.size();
            trie.emplace_back();
        }
        u = trie[u].ch[b];
    }
}

int query(const int& x) {
    int u = 0, res = 0;
    for (int i = 30; i >= 0; i--) {
        int b = (x >> i) & 1;
        int t = b ^ 1;              // 使得异或值更大必然要取相反位
        if (trie[u].ch[t]) {
            res |= (1 << i);        // 将第i位设置为1
            u = trie[u].ch[t];
        } else u = trie[u].ch[b];
    }
    return res;
}
