    You are given an integer sequence $a_{0},a_{1},\dots,a_{n-1}$ of length $n$.
Construct an $n\times n$ grid, with both row and column indices starting from $0$. The $0$
-th column, from top to bottom, is $a_{0},a_{1},\dots,a_{n-1}$. Starting from the $1$
-st column, each column is obtained by cyclically shifting the previous column down by one cell.
Formally, if the number in row $i$ and column $j$ is $b_{i,j}$, then
$ j=0, b_{i,j}=a_{i} $
$ j>0, b_{i,j}=b_{(i+n-1)\bmod n, j-1} $
You are at the upper-left corner $(0,0)$. In each step, you may only move right or down, until you reach the lower-right corner $(n-1,n-1)$. Every grid cell visited by the path is counted, including the starting and ending cells.
Please find the minimum possible sum of the weights of the grid cells visited by the path.

For each test case, the first line contains one integer $n(1\le n\le 10^5)$, denoting the length of the integer sequence.
The second line contains $n$ integers $a_{0},a_{1},\dots,a_{n-1}(0\le a_{i}\le 10^9)$, denoting the integer sequence.
It is guaranteed that, within each test file, the sum of $n$ over all test cases does not exceed $10^5$.

# C.小月的排序
## 题目详情
$\hspace{15pt}$小月需要把 $n$ 个非负整数 $a_1,a_2,\dots,a_n$ 按固定规则从小到大排列。  
$\hspace{15pt}$对于两个非负整数，她将依次按照以下三条规则比较判断两数的大小顺序，如果按前一条规则无法判断两数的大小，则继续按下一条规则判断：  
$\hspace{23pt}\bullet\,$二进制表示中 $1$ 的数量较少的数更小；  
$\hspace{23pt}\bullet\,$最低位 $1$ 所在位更低的数更小；  
$\hspace{23pt}\bullet\,$直接比较数值，更小的数更小。  
$\hspace{15pt}$特殊的，我们认为 $0$ 的最低位 $1$ 位于从低位到高位的第 $31$ 位，其中最低位为第 $0$ 位。

*Input*
$\hspace{15pt}$第一行输入两个整数 $n$ 和 $k\left(1\leqq k\leqq n\leqq 2\times 10^5\right)$。  
$\hspace{15pt}$第二行输入 $n$ 个非负整数 $a_1,a_2,\dots,a_n\left(0\leqq a_i<2^{31}\right)$。
*OutPut*
$\hspace{15pt}$输出一个整数，表示排序后的第 $k$ 个元素。

$\hspace{23pt}\bullet\,$是极大的，即不能再通过添加原图中的其他方格而依旧保持连通性；

$\hspace{15pt}$$\operatorname{xor}^\texttt{[2]}$：指位运算中的按位异或（Bitwise XOR），对两个整数的二进制表示按位进行异或运算。如果您需要更多位运算相关的知识，可以参考 [**OI-Wiki的相关章节**](https://oi-wiki.org/math/bit/#%E4%B8%8E%E6%88%96%E5%BC%82%E6%88%96)。

$\hspace{15pt}$第二行输入 $n$ 个非负整数 $a_1,a_2,\dots,a_n\left(0\leqq a_i<2^{30}\right)$，表示各个筹码上的数值。
