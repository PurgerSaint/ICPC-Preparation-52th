# 制度卡（裁定汇总 · 10.14 重排）
> 这一节是"机械规则"，不靠直觉执行。每条后面是它诞生的病灶——同族错误再现时先回这张卡，不要重新发明。

## 1. 闸门与止损
- **赛时识题协议**：开场 30 分钟读全卷，每题 3 分钟抓"输出要求 / 数据范围 / 题型关键词"并标防区；每 30 分钟看榜，主攻高 AC 率且属我方或交集防区的题；**判断超时前必须在纸面算复杂度**。
- 读题死锁 **20 分钟** → 全文/关键句翻译；单题思考上限 **30 分钟** → AI/题解门；每题总耗 **≤1h**；赛时单题盒 **45 分钟**。
- **信号灯清单（见到即停手，不等超时）**：①在"最大化最小值/最小化最大值"题里逐步模拟操作顺序 ②开始枚举第 3 个局部 case ③AC 后写不出一行判据 ④`solve()` 里 `return` 超过 4 个。
- **两次 WA 后禁止打补丁**：第 3 次提交前必须在报告里写 ≤3 行判据（哪个量恒定 / 一次操作让哪个量变多少 / 上下界），并证明它；写不出就不许再改代码。物证：新生赛 D 7 发 WA/157 分钟、2271D 两版特判堆叠。

## 2. 读题与建模（首要失分源，跨赛季一致）
- **两段式翻译**：先读英文原文，对关键限制句**逐字直译**写在草稿上（B 题 19/36、K 题信号规则、2275C 的"use a 64-bit type"正是病灶），再全文译中文深化。翻译不通处 = 理解盲点。
- **4 行建模协议**（写代码前）：点是什么 / 边是什么 / 有向还是无向 / 度数与连通性有什么保证。1833E 只要写下"边是无向的"这一行，1h16m 就不会发生。
- **题面注释也是题面**；自洽误读能过样例——**动手前用手算样例核对定义**，定义题尤其。
- **数据范围门**：从 Constraints 段算枚举量，不是从样例感觉。范围 2e5/1e9 时不存在"这题数据很小"。

## 3. 实现前审计
- **二分答案的 check ≠ 过程模拟**：check(S) 必须独立计算每个元素达到 S 的代价；log 因子是免费的，模拟是致命的。
- **类型溢出三规则**：①表达式类型由操作数决定，不由接收变量决定（`1LL*` 要打在乘法侧，"到处加 1LL"不是解法）②计数/求和题提交前做 30 秒上界审计并写进注释 ③"赛时 AC、赛后重判 WA"= 大输入 bug 的签名，先查溢出/O(n²)/数组开小三条，不要重新怀疑算法。
- **归因纪律**：讲不出机制的修复不算修复；**不逐字接受 AI 给的错误解释**（Gemini 的 size_t 溢出说在 C++ 里站不住）；每记一笔错误，标 R 读题 / E 实现 / U 理解。

## 4. 暴力与对拍
- 暴力合法的唯一入口是**规模核算**（题面 Constraints）；穷举 ≠ 启发式（打分贪心走位不在许可内）。
- 凡提交暴力，同目录必须留一份数学版并与暴力对拍——暴力是**校验器**，不是归宿。物证：10.09 打表从不调用、10.11 正确暴力与 24.9% 错的"数学版"共存却未互相调用。
