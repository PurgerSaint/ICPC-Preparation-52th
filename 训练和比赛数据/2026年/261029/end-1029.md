## 题目详情
Li Hua has a pattern of size $n\times n$, each cell is either blue or red. He can perform **exactly $k$** operations. In each operation, he chooses a cell and changes its color from red to blue or from blue to red. Each cell can be chosen as many times as he wants. Is it possible to make the pattern, that matches its rotation by $180^{\circ}$?
Suppose you were Li Hua, please solve this problem.
**Input**
The first line contains the single integer $t$ ($1 \le t \le 100$) — the number of test cases.
The first line of each test case contains two integers $n,k$ ($1\le n\le 10^3,0\le k \le 10^9$) — the size of the pattern and the number of operations.
Each of next $n$ lines contains $n$ integers $a_{i,j}$ ($a_{i,j}\in\{0,1\}$) — the initial color of the cell, $0$ for blue and $1$ for red.
It's guaranteed that sum of $n$ over all test cases does not exceed $10^3$.
**Output**
For each set of input, print "YES" if it's possible to make the pattern, that matches its rotation by $180^{\circ}$ after applying exactly $k$ of operations, and "NO" otherwise.
You can output the answer in any case (upper or lower). For example, the strings "yEs", "yes", "Yes", and "YES" will be recognized as positive responses.
## 提交详情
- 提交时间:15:32 状态:WA 详细状态:`Wrong answer on test 3`
> rotation 旋转  
翻转 $k$ 个方格的颜色，使得翻转后图像为原图像180度的旋转  
第 $i$ 行 $j$ 列在旋转180度后的位置位于第 $(n-1)-i$ 行第 $(n-1)-j$ 列  
计算翻转前后的异同，如果正好有 $k$ 个不同，直接返回`YES`即可  
不同的正好是从 $0$ 到 $1$ ，或从 $1$ 到 $0$ 的相反  
每个不同点必然对应两个不同，即当前点A对应另一个点B，而另一个点B又对应当前点A  
且这两个不同必然包含从 $0$ 到 $1$ 和从 $1$ 到 $0$ ，那么只要将其中一个`1`换成`0`即可  
故只用计算不同点数量 $diff$ ，得到 $ans=k-\frac{diff}{2}$ ，那么答案就是 $0\le ans\le k$ 且 $ans\bmod 2=0$  
这里的 $ans\bmod 2=0$ 代表剩下次数 $ans$ 可以随意翻转 $\frac{ans}{2}$ 个方格，每个方格翻转两次(等于没翻转)

无论 $ans$ 的奇偶，就算是奇数，我花费一次将一对异同点中的`0`换成`1`即可，剩下的 $ans$ 依然为偶数

# 1739B.Array Recovery

## 题目详情
For an array of **non-negative** integers $a$ of size $n$, we construct another array $d$ as follows: $d_1 = a_1$, $d_i = |a_i - a_{i - 1}|$ for $2 \le i \le n$.
Your task is to restore the array $a$ from a given array $d$, or to report that there are multiple possible arrays.
**Input**
The first line contains a single integer $t$ ($1 \le t \le 100$) — the number of test cases.
The first line of each test case contains one integer $n$ ($1 \le n \le 100$) — the size of the arrays $a$ and $d$.
The second line contains $n$ integers $d_1, d_2, \dots, d_n$ ($0 \le d_i \le 100$) — the elements of the array $d$.
It can be shown that there always exists at least one suitable array $a$ under these constraints.
**Output**
For each test case, print the elements of the array $a$, if there is only one possible array $a$. Otherwise, print $-1$.
## 提交详情
- 提交时间:16:58 状态:AC 详细状态:`-`
> 从数组 $d$ 还原为非负数组 $a$ ，其中对于 $2\le i\le n$ 定义为 $d_{i}=|a_{i}-a_{i-1}|$ ，其中 $d_{1}=a_{1}, i=1$  
如果只有一种还原的 $a$ ，输出他，否则输出 $-1$  
对于任何一个 $d_{i}(2\le i\le n)$ ，可以将 $a_{i}$ 设为 $a_{i-1}+d_{i}$ 或 $a_{i-1}-d_{i}$  
由于必须保证 $a_{i}\ge 0$ ，题目可还原的 $a$ 可以是一个决策树，有多种还原情况  
但题目仅要求判断是否存在多种可能性与一种可能性，即只要出现决策树分叉，就直接判否即可  
由于初始构造方法是构造为 $a_{i}:=a_{i-1}+d_{i}$ ，对于分叉，当且仅当出现 $a_{i-1}-d_{i}\ge 0$ 就行

## 题目详情
You are given a $2 \times n$ grid filled with zeros and ones. Let the number at the intersection of the $i$\-th row and the $j$\-th column be $a_{ij}$.
There is a grasshopper at the top-left cell $(1, 1)$ that can only jump one cell right or downwards. It wants to reach the bottom-right cell $(2, n)$. Consider the binary string of length $n+1$ consisting of numbers written in cells of the path without changing their order.
Your goal is to:
1.  Find the lexicographically smallest$^\dagger$ string you can attain by choosing any available path;
2.  Find the number of paths that yield this lexicographically smallest string.
$^\dagger$ If two strings $s$ and $t$ have the same length, then $s$ is lexicographically smaller than $t$ if and only if in the first position where $s$ and $t$ differ, the string $s$ has a smaller element than the corresponding element in $t$.
**Input**
Each test contains multiple test cases. The first line contains the number of test cases $t$ ($1 \le t \le 10^4$). The description of the test cases follows.
The first line of each test case contains a single integer $n$ ($2 \le n \le 2 \cdot 10^5$).
The second line of each test case contains a binary string $a_{11} a_{12} \ldots a_{1n}$ ($a_{1i}$ is either $0$ or $1$).
The third line of each test case contains a binary string $a_{21} a_{22} \ldots a_{2n}$ ($a_{2i}$ is either $0$ or $1$).
It is guaranteed that the sum of $n$ over all test cases does not exceed $2 \cdot 10^5$.
**Output**
For each test case, output two lines:
1.  The lexicographically smallest string you can attain by choosing any available path;
2.  The number of paths that yield this string.
