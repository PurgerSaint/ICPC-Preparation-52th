> 进货一个桃子需要 $x$ 元，一个篮子要 $y$ 元，然后进货商只有 $s$ 元和 $m$ 个桃子  
有 $n$ 个人，每个人会以 $a_{i}$ 元买 $k$ 个桃子和要 $b_{i}$ 个篮子

```cpp
ll dfs(int i, ll g, ll ls) {
    if (g == m || ls == 0) return 0;
    if (i >= n || g >= m || ls < 0) return -1;
    ll t = k * x + a[i].second * y, res = -1;
    ll ans = 0;
    if ((res = dfs(i + 1, g, ls)) != -1) ans = res;
```  

我就改写了我的DFS方法，将其转为一次性的循环操作  
由于每个人的购买数量固定，可以将他们分别记录为需要篮子的 $p1$ 和不需要篮子的 $p2$  
然后对 $p1,p2$ 进行降序排序，同时再对他们做前缀和，以便后面快速得到  
循环从 $1$ 到 $n$ 的每个 $i$ ，代表选择了 $i$ 个桃子带篮子的人  
然后对每个 $i$ ，计算不选当前人和选当前人的情况，记录最后的最大值即可，代码如下:  
```cpp
ll ans = 0, get = 0, less = s;
const ll b1 = k * x;    // 固定成本
for (int i = 1; i <= m1; i++) {
    // lm为当前剩余的钱，减去前面 i-1 个人带篮子的成本，带篮子成本为 b1+y  
    // la为当前剩余的桃子数量
    ll lm = s - (i - 1) * (b1 + y), la = m - (i - 1) * k;
    if (lm >= 0 || la >= 0)
        ans = max(ans, s1[i - 1] + s2[min(max(lm, 0LL) / b1, min(1LL * m2, max(la, 0LL)))]);
    
    // 再计算选当前人能得到的总桃子数量
    lm = s - i * (b1 + y), la = m - i * k;
    if (lm >= 0 || la >= 0)
        ans = max(ans, s1[i] + s2[min(max(lm, 0LL) / b1, min(1LL * m2, max(la, 0LL)))]);
}
```
