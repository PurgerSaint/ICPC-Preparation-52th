# A.平衡问题
## 题目详情
Bobo 有一块刚性薄板，它的重心只可能位于点 $P$ 或点 $Q$ 处。Bobo 想通过一次支撑实验，测定重心究竟在哪一点。
具体而言，他会在薄板下方放置三根等高的支柱，将薄板水平置于支柱上并松手。根据物理规律，薄板在松手后能够保持平衡，当且仅当它的重心严格位于三个支撑点所围成的三角形内部。
为此，Bobo 在薄板上预先标出了 $N$ 个候选支撑点 $A_1, A_2, \dots, A_N$。现在，Bobo 准备从这 $N$ 个候选支撑点中选出三个不同的点来架设支柱。如果他希望仅凭松手后薄板是否保持平衡，就能唯一确定重心位于 $P$ 还是 $Q$，共有多少种不同的选点方案？
**input**
第一行包含一个整数 $T$（$1 \le T \le 1000$），表示测试数据组数。
对于每组测试数据：
* 第一行包含一个整数 $N$（$3 \le N \le 2 \times 10^5$），表示候选支撑点的数量。
* 第二行包含两个整数 $x_P, y_P$，表示重心候选点 $P$ 的坐标。
* 第三行包含两个整数 $x_Q, y_Q$，表示重心候选点 $Q$ 的坐标。
* 接下来 $N$ 行，每行包含两个整数 $x_i, y_i$，表示候选支撑点 $A_i$ 的坐标。
所有输入坐标均满足 $-10^9 \le x, y \le 10^9$。保证每组测试数据的 $N + 2$ 个点两两不同，且其中任意三个点都不共线。保证所有测试数据的 $N$ 之和不超过 $2 \times 10^5$。
**output**
对于每组测试数据，输出一行，包含一个整数，表示选点方案的数量。

# B.血染钟楼（Blood on the Clocktower）
## 题目详情
《血染钟楼》是一款备受好评的桌游。Bobo 和朋友们相约体验这款游戏。
本局游戏共有 $n$ 名玩家，编号为 $1$ 到 $n$。初始时，所有玩家均存活，且恰有一名玩家的身份是小恶魔，但具体是哪位玩家尚不清楚。此外，场外还有一位不属于这 $n$ 名玩家的占卜师，占卜师始终存活且永远不会成为小恶魔。
游戏共进行 $m$ 个夜晚。在第 $i$ 个夜晚，按先后顺序发生以下两件事：
1. 占卜：占卜师查验两名不同的存活玩家 $a_i$ 和 $b_i$。若此时两人中恰有一人是小恶魔，则真实查验结果应为 $1$；否则应为 $0$。占卜师记录下的结果为 $c_i$，但该记录可能有误。若 $c_i$ 与真实查验结果不同，就称第 $i$ 条记录为一条错误记录。
2. 死亡与传位：存活玩家 $d_i$ 死亡，此后不再复活。若 $d_i$ 死亡时是小恶魔，则必须从此时仍然存活的玩家中任选一人继承小恶魔身份；否则，不发生小恶魔身份的转移。
注意：小恶魔的身份转移发生在该夜占卜之后，因此不会影响当晚的真实查验结果。
Bobo 想知道，在所有符合上述规则的“初始小恶魔身份”及“历次小恶魔传位对象”的合法指派方案中，最少会产生多少条错误记录？
**input**
第一行包含两个整数 $n, m$（$2 \le n \le 5 \times 10^5$，$1 \le m < n$），分别表示玩家人数与夜晚数量。
接下来 $m$ 行，第 $i$ 行包含四个整数 $a_i, b_i, c_i, d_i$（$1 \le a_i, b_i, d_i \le n$，$a_i \ne b_i$，$c_i \in \{0, 1\}$），依次表示第 $i$ 夜被查验的两名玩家、记录的查验结果以及当晚死亡的玩家。
保证 $d_1, d_2, \dots, d_m$ 两两不同，且 $a_i, b_i, d_i$ 在第 $i$ 夜开始时均存活。
**output**
输出一行一个整数，表示最少可能出现的错误记录条数。

# C.步步登高（Climbing Higher）
## 题目详情
Boboland 有一条穿行于山间的观光步道，东西两端各设有一个入口。沿步道从西到东依次分布着 $n$ 座观景台，它们的海拔互不相同。
景区推出了一项名为“步步登高”的打卡活动。游客可以从任意一个入口进入，沿步道向另一端行进，并选择沿途的若干座观景台打卡。活动的规则是：每次打卡的观景台，都必须比上一次打卡的观景台海拔更高。游客可以经过某座观景台而不打卡，也可以在途中结束游览。
为了方便游客根据行程安排打卡路线，景区分别统计了从两个入口进入时，在不同游览范围内最多能够打卡的观景台数量。对于每个 $1 \le i \le n$：
1. 从西端进入，向东行进，且只游览最西边的 $i$ 座观景台时，最多能够打卡 $a_i$ 座观景台。
2. 从东端进入，向西行进，且只游览最东边的 $i$ 座观景台时，最多能够打卡 $b_i$ 座观景台。
Bobo 正在整理这条步道的游览指南，却发现手头只有这两份统计记录，没有各座观景台的海拔信息。你能根据这些记录，帮他还原一种可能的观景台海拔分布吗？
**input**
第一行包含一个整数 $T$（$1 \le T \le 5 \times 10^5$），表示测试数据组数。
对于每组测试数据：
* 第一行包含一个整数 $n$（$1 \le n \le 5 \times 10^5$）；
* 第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$（$1 \le a_i \le n$）；
* 第三行包含 $n$ 个整数 $b_1, b_2, \dots, b_n$（$1 \le b_i \le n$）。
保证所有测试数据的 $n$ 之和不超过 $5 \times 10^5$。
**output**
对于每组测试数据，输出一行：若不存在满足条件的观景台海拔分布，输出 `-1`；否则输出 $n$ 个用空格分隔的整数 $h_1, h_2, \dots, h_n$（$1 \le h_i \le n$），其中 $h_i$ 表示第 $i$ 号观景台的海拔。若有多种合法方案，输出任意一种即可。

# D.殊途同归（Different Paths, Same Destination）
## 题目详情
Boboland 将举办一场集章旅行活动。在这场集章旅行活动中，参与者将带着一本集章册，沿着一条无限长的单行公路旅行，收集 $n$ 种不同的纪念印章。
为了方便集章，每种印章都在沿途设有多个盖章点。第 $i$ 种印章的盖章点以 $m_i$ 距离等间距分布，其中一处位于坐标 $a_i$。例如，当 $m_i = 3, a_i = 1$，该种印章的盖章点将在坐标 $\dots, -5, -2, 1, 4, \dots$ 处分布。
出发前，参与者会将这 $n$ 种印章按照某种顺序排成一份清单，每种印章恰好出现一次，随后严格按照清单上的顺序依次集章：
* 每次只寻找清单上的下一种印章，并前往前方最近的一个对应盖章点。
* 如果当前位置就能盖到这种印章，他便直接在原地盖章，无须继续前进。
集齐全部 $n$ 种印章后，参与者便在当前位置结束旅程。
Bobo 想知道，每个人的最终结束位置是否仅与初始位置有关，而与印章排列顺序无关。
**input**
第一行包含一个整数 $T$（$1 \le T \le 2 \times 10^5$），表示测试数据组数。
对于每组测试数据：
* 第一行包含一个整数 $n$（$1 \le n \le 2 \times 10^5$），表示印章种类数；
* 接下来 $n$ 行，第 $i$ 行包含两个整数 $a_i, m_i$（$0 \le a_i \le 10^{18}, 1 \le m_i \le 10^{18}$）。
保证所有测试数据的 $n$ 之和不超过 $2 \times 10^5$。
**output**
对于每组测试数据，如果每个人的最终结束位置仅与初始位置有关，而和印章排列顺序无关，输出一行 `YES`；否则输出一行 `NO`。

# F.烽火轮转（Flames in Rotation）
## 题目详情
Boboland 的边境上，从左到右排列着 $n$ 座信号塔。它们的编号依次为 $a_1, a_2, \dots, a_n$，其中 $a_1, a_2, \dots, a_n$ 是 $1, 2, \dots, n$ 的一个排列。
由于信号干扰，相邻的两座信号塔不能同时工作。为此，Bobo 设计了一套自动启动系统。每次启动时，系统会选择一个起始编号 $k$，按照编号 $k, k+1, \dots, n, 1, 2, \dots, k-1$ 的顺序，依次尝试启动所有信号塔，具体规则如下：
1. 初始时，所有信号塔均处于关闭状态。

string solve() {
    int n, k; cin >> n >> k;
    string s; cin >> s;
    string t = s;
    sort(range(t));
    if (s == t || k == n) return t;
    vector<int> a, b;
    for (int i = 0; i < n; i++)
        if (s[i] == '1')
            a.push_back(i);
    for (int i = n - 1; i >= 0; i--)
        if (s[i] == '0')
            b.push_back(i);
    if (a.empty() || b.empty()) return s;
    int cnt = k / 2;
    // cout << cnt << " " << a.size() << " " << b.size() << "\n";
    for (int i = 0; i < min(cnt, (int)min(a.size(), b.size())); i++) {
        if (a[i] > b[i]) break;
        swap(s[a[i]], s[b[i]]);
    }
    return s;
}

    vector<int> a(n), b(n);
    for (int& t: a) cin >> t;
    for (int& t: b) cin >> t;
    vector<bool> vis(n + 1, 0);

            return;
        }

        vis[x] = 1;

            return;
