# C.Permutation Inversions

## 题目详情
There is an unknown permutation p = $(p1, p2,\dots ,pn)$ of the integers $1,2,\dots , n$. You are given m pieces
of information about this permutation.
Each piece of information consists of an interval $[r_{i},l_{i}]$ and a permutation $q_{i,1}, q_{i,2}, \dots , q_{i,r_{i}−l_{i}+1}$ of the
indices in this interval. It states that
$p_{q_{i,1}} < p_{q_{i,2}} < \dots < p_{q_{i,r_{i}−l_{i}+1}}$.
Your task is to find a permutation that satisfies all the given information and has the minimum possible
number of inversions. If no such permutation exists, output −1.
If several optimal permutations exist, output any of them.
The number of inversions of a permutation p is the number of pairs of indices (x, y) such that
$1 ≤ x < y ≤ n and p_{x} > p_{y}$.
*Input*
The first line contains a single integer T ($1 ≤ T ≤ 10^6$) — the number of test cases.
For each test case:
- The first line contains two integers n (1 ≤ n ≤ 10^6) and m (1 ≤ m ≤ 10^6) — the size of the permutation
and the number of constraints.
- Each of the next m lines describes a constraint. The i-th constraint starts with two integers $l_{i}$ and $r_{i}$
($1 ≤ r{i} ≤ l_{i} ≤ n$), followed by $r{i}-l_{i}+1$ integers $q_{i,1}, q_{i,2},\dots ,q_{i,r_{i}−l_{i}+1}$, which form a permutation of the integers from li to r_{i}.
It is guaranteed that $1 ≤ \sum n ≤ 10^6$, $1 ≤ \sum m ≤ 10^6$, and $1 ≤ \sum_{i=1}^{m} (r{i}-l_{i}+1) ≤ 10^6$ over all test cases.
*Output*
For each test case, print a single line:
- If no satisfying permutation exists, print -1.
- Otherwise, print n space-separated integers p1, p2, . . . , pn representing a valid permutation that minimizes the number of inversions.
If there are multiple optimal permutations, print any of them.

> `inversions`是逆序对的意思，然后题目是要求在满足规则的情况，最小化所得序列的逆序对个数  
对于第 $i$ 个规则，要求最终序列中 $p_{q_{i,1}} < p_{q_{i,2}} < \dots < p_{q_{i,r_{i}−l_{i}+1}}$  
那么就可以建图，因为存在先大后小的关系，即固定某位置的数必然要小于另一部分位置中的数  
这样反序建得邻接图，即首先将大的数放到第一个位置，然后再逐步根据图链放置剩余的数  
这样放置还能避免出现数重复  
根据图链操作下来，发现是按拓扑序进行枚举放置的  
然后由于要逆序对数量最小，那么就将拓扑的队列换成最大堆的优先序列，以保证最大的下标得到的数尽可能大，使得全局逆序对数量尽可能少  
无法构造即代表先后次序发生冲突，即存在双向边，那么就使用拓扑的判环规则，双向边为最小周长的环

## 题目详情
There is an initially empty stack S. A sequence of operations is then performed on it. There are three types of operations:
• "+ x"means pushing the element x onto the stack.
• "? x"means querying whether the element x exists in the stack. There are two possible results:
– "T x"means that the element x exists.
– "F x"means that the element x does not exist.
• "−"means popping the top element from the stack (the stack must be nonempty).
Little G recorded all "+ x "T x and "F x operations during the entire process, but did not record any "−"operations.
Now, Little G wants to insert some "−"operations into the recorded operation sequence such that:
• At all times, all elements in the stack are distinct.
• The results of all "? x"queries are consistent with the operation sequence you construct.
It is guaranteed that at least one valid reconstructed sequence exists.
*Input*
There are multiple test cases.
The first line of the input contains an integer T ($1 ≤ T ≤ 10^5$), representing the number of test cases.
Each test case is described as follows:
For each test case:
• The first line contains a positive integer n ($1 ≤ n ≤ 10^6$).
• Each of the next n lines is in the form "+ x "T x or "F x representing a recorded operation. It is guaranteed that $1 ≤ x ≤ 10^9$.
It is guaranteed that $1 ≤ \sum n ≤ 10^6$.
*Output*
For each test case, output one line containing a string consisting only of the characters "+ "? and "− representing the operation sequence you reconstruct, where:
• If the i-th character is "+ then the i-th operation in your reconstructed sequence pushes an element onto the stack.
• If the i-th character is "? then the i-th operation in your reconstructed sequence queries whether an element exists in the stack.
• If the i-th character is "− then the i-th operation in your reconstructed sequence pops the top element from the stack.
If there are multiple possible original operation sequences, you may reconstruct any one of them.

> Gemini的操作是计算每一个入栈元素`x`操作的寿命，其寿命为元素`x`最近判否操作之前最后一个判在操作的位置  
然后模拟一个栈，根据栈顶的入栈操作寿命`l`是否满足 $l<=i$ 决定是否栈顶出栈，是否执行出栈操作  
同时也定义每一个判否（`F`）操作之前为一个元素的生命周期，因为判否操作时，栈内必须不存在该元素  
Gemini使用了一个绝妙的降维操作，他倒序访问所有操作  
这样就使得在元素每个生命周期内，对于每个`T`仅保留最近的入栈操作，其他的入栈操作均会在入栈后立刻出栈   
简单来说，就是按生命周期维护每个元素的寿命  
一个元素遇到了判否操作时，栈内不能出现该元素，故可以用判否操作来作为这个元素的寿命周期结束点  
我赛中“维护每个元素仅留有一个”，在Gemini想法中的体现，就是每个判在操作均由最近的入栈操作所支持  
那么生命周期内，除了被支持的入栈操作，其余的入栈操作均需要入栈后就出栈  
从前往后如此操作，需要维护三个`map<ll, vector<int>>`极其麻烦  
故可以反向操作，仅维护一个`map<ll,int>`作为生命周期内判在操作的最后一个位置  
于判否时清空，因为不能跨生命周期支持   
于入栈时根据当前入栈操作是否需要支持后续的判在操作，即map中是否能找到生命周期内最后一个判在操作位置
关键点是对每个入栈操作评价得到该操作的寿命  
后续的出栈判断及用栈模拟，也是根据栈顶的入栈操作寿命进行的操作
