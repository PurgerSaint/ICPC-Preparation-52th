# A.小月的贴纸
## 题目详情
$\hspace{15pt}$小月有 $n$ 段纸带，每段纸带的两端各有一张贴纸。  
$\hspace{15pt}$她将这些纸带首尾相接拼成一条单链。在每个连接处，相邻两段纸带的贴纸会完全重叠，此时两张重叠的贴纸只能看见一张。  
$\hspace{15pt}$请计算拼接后最终能看见多少张贴纸。
*input*
$\hspace{15pt}$输入一个整数 $n\left(1\leqq n\leqq100\right)$，表示纸带的段数。
*output*
$\hspace{15pt}$输出一个整数，表示能看见的贴纸张数。
## 提交详情
- 提交时间:19:03:20 状态:AC 详细状态:`-`
> 一张纸带有左右两侧贴纸，将两张纸带相连，纸带中间的贴纸会变成一个  
故答案就是 $n + 1$

# B.小月的周长
## 题目详情
$\hspace{15pt}$小月有一张由 $n \times m$ 个单位正方形纸片按照 $n$ 行 $m$ 列摆放得到的长方形纸。单位正方形纸片的边长为 $1$。  
$\hspace{15pt}$现在她将第 $x$ 行和第 $y$ 列的所有正方形纸片移除。剩余未被移除的正方形纸片保持原位，请计算这些剩余正方形纸片组成图形的周长之和。
*input*
$\hspace{15pt}$每个测试文件均包含多组测试数据。第一行输入一个整数 $T\left(1\leqq T\leqq 10^3\right)$ 代表数据组数，每组测试数据描述如下：  
$\hspace{15pt}$第一行输入四个整数 $n,m,x,y\left(1\leqq n,m\leqq 50;\ 1\leqq x\leqq n;\ 1\leqq y\leqq m\right)$，表示纸的行数、列数、取走的行、列。  
$\hspace{15pt}$除此之外，保证单个测试文件的 $n\times m$ 之和不超过 $2\times 10^5$。
*output*
$\hspace{15pt}$对于每一组测试数据，新起一行。输出一个整数，表示剩余纸片的周长之和。
## 提交详情
- 提交时间:19:11:26 状态: 详细状态:`-`
> 移除之前该矩形的周长为 $2(n + m)$   
如果移除的是四周的行列，其周长变为 $2(n - 1 + m - 1) = 2(n + m - 2)$  
如果移除的是中间的行列，其周长变为 $4(n - 1) + 4(m - 1)$  
接下来就是行列交替四周和中间，为了避免计算麻烦，只能对行和列单独处理，最后通过

# C.小月的数码轮
## 题目详情
$\hspace{15pt}$小月把 $n$ 个数码轮排成一行，每个数码轮显示一个十进制数字。初始时数码轮显示的数字用一个长为 $n$ 的字符串 $s =s_1s_2\dots s_n$ 表示，其中 $s_n$ 表示个位，$s_{n-1}$ 表示十位，以此类推。  
$\hspace{15pt}$每按一次按钮，所有数码轮都会向前转动一格：$0$ 变成 $1$，$1$ 变成 $2$，依此类推，$9$ 变成 $0$。  
$\hspace{15pt}$小月准备选择一个整数 $x\left(0\leqq x\leqq9\right)$，使得按 $x$ 次按钮后，数码轮表示的十进制整数被给定的整数 $m$ 整除。请统计有多少种可选择的 $x$。  
$\hspace{15pt}$读出的数字串允许包含前导零。例如，$\texttt{"008"}$ 表示整数 $8$，$\texttt{"000"}$ 表示整数 $0$。整数 $0$ 能被任意正整数整除。
*input*
$\hspace{15pt}$第一行输入两个整数 $n,m\left(1\leqq n\leqq2\times10^5;\ 1\leqq m\leqq10^9\right)$，分别表示数码轮数量、除数。  
$\hspace{15pt}$第二行输入一个长度为 $n$、仅由十进制数字构成的字符串 $s$，表示初始读数。
*output*
$\hspace{15pt}$输出一个整数，表示满足要求的按钮次数 $x$ 的数量。
## 提交详情
- 提交时间: 状态: 详细状态:`-`
> 给与一个长度为 $n$ 的数论，数论里每一位都是1到10的个位数  
按一次按钮每一位都往前推进一位，9的下一位是0  
已知0是任何数的倍数，求有多少种方案，即每种方案都可以按若干下使得数论显示的数字是 $m$ 的倍数

# D.小月的字带
## 题目详情
$\hspace{15pt}$小月有一个字带，最初字带上的字符串只包含一个字符 $c_0$。  
$\hspace{15pt}$她会进行 $n$ 次复制操作，用字符序列 $c_1,c_2,\dots,c_n$ 表示，第 $i$ 次复制的流程为：  
$\hspace{23pt}\bullet\,$设本次复制开始时字带上的字符串为 $s$；  
$\hspace{23pt}\bullet\,$设将 $s$ 左右翻转后得到字符串 $s^\prime$；  
$\hspace{23pt}\bullet\,$将字带上的字符串替换为 $sc_is^\prime$，也就是将 $s$，$c_i$，$s^\prime$ 按顺序拼接后得到的字符串。  
$\hspace{15pt}$例如，字带为 $\texttt{ab}$，本轮字符为 $\texttt{d}$ 时，复制后字带上的字符串会被替换为 $\texttt{abdba}$。  
$\hspace{15pt}$请你计算，完成全部复制后，字带上的字符串中有多少对相同的相邻字符？
*input*
$\hspace{15pt}$第一行依次输入一个整数和一个小写字母 $n,c_0\left(0\leqq n\leqq60\right)$，表示复制轮数、初始字符。  
$\hspace{15pt}$第二行输入 $n$ 个小写字母 $c_1,c_2,\dots,c_n$，表示各轮使用的字符。若 $n=0$，则输入不存在第二行。
*output*
$\hspace{15pt}$输出一个整数，表示最终字带中相邻相同字符对的数量。
## 提交详情
- 提交时间:19:27:52 状态:MLE 详细状态:`-`
> 纯模拟，每次用翻转函数进行翻转，然后再拼接  
- 提交时间:19:35:04 状态:AC 详细状态:`-`
> 由第一次的模拟可得知，每次拼接前后，对于 $c_{i}$ 的左右都是给与的 $c_{0}$  
那么只要记录已有次数，循环时只要给已有次数乘二，然后再判断当前字符 $c_{i}$ 是否同 $c_{0}$ ，是的话再加2即可

# E.小月的区间
## 题目详情
$\hspace{15pt}$小月有一个长度为 $n$ 的排列$^\texttt{[1]}$ $a = a_1,a_2,\dots, a_n$。  
$\hspace{15pt}$她称一个非空子数组$^\texttt{[2]}$ $[l,r]$ 是**新鲜**的，当且仅当它同时满足以下两个条件：  
$\hspace{23pt}\bullet\,$数组中的最大值，大于所有位于数组左侧的元素，即大于每个 $a_i\left(i\lt l\right)$；  
$\hspace{23pt}\bullet\,$数组中的最小值，小于所有位于数组右侧的元素，即小于每个 $a_i\left(i>r\right)$。  
$\hspace{15pt}$请你统计**新鲜**子数组的数量。  
【名词解释】  
$\hspace{15pt}$长度为 $n$ 的排列$^\texttt{[1]}$：由 $1,2,\dots,n$ 这 $n$ 个整数、按任意顺序组成的数组（每个整数均恰好出现一次）。例如，$\{2,3,1,5,4\}$ 是一个长度为 $5$ 的排列，而 $\{1,2,2\}$ 和 $\{1,3,4\}$ 都不是排列，因为前者存在重复元素，后者包含了超出范围的数。  
$\hspace{15pt}$子数组$^\texttt{[2]}$：从原数组中，连续的选择一段元素（可以全选、可以不选）得到的新数组。由原数组的第 $l$ 个元素到第 $r$ 个元素组成的子数组可以用 $\left[l,r \right]$ 表示。
*input*
$\hspace{15pt}$第一行输入一个整数 $n\left(1\leqq n\leqq2\times10^5\right)$。  
$\hspace{15pt}$第二行输入 $n$ 个整数 $a_1,a_2,\dots,a_n\left(1\leqq a_i\leqq n\right)$。
*output*
$\hspace{15pt}$输出一个整数，代表**新鲜**子数组的数量。
## 提交详情
- 提交时间: 状态: 详细状态:`-`
> 从左到右记录比前面大的数的数量，然后从右到左记录比后面小的数量  
已知整体可以作为一个新鲜字符串，左右两个单独元素是否能成立，还是得看是否满足  
我将上述改成了实时推进，即只记录后缀最小数量，实时推进前缀最大数量并更新  
代码如下:
```cpp
int main() {
    ios;
    int n; cin >> n;
    vector<int> a(n);
    for (int& t: a) cin >> t;
    vector<int> mn;
    int nx = n + 1;
    for (int i = n - 1; i >= 0; i--) {
        if (a[i] < nx) {
            nx = a[i];
            mn.push_back(i);
        }
    }
    // for (auto it = mn.begin(); it != mn.end(); it++)
    //    cout << *it << (it + 1 != mn.end() ? " " : "\n");
    ll ans = 0;
    int px = 0;
    for (int i = 0; i < n; i++) {
        while (!mn.empty() && mn.back() < i) mn.pop_back();
        if (mn.empty()) break;
        if (a[i] > px) {
            cout << i << " " << mn.size() << "\n";
            px = a[i];
            ans += mn.size();
        }
    }
    cout << ans;
    return 0;
}
```
