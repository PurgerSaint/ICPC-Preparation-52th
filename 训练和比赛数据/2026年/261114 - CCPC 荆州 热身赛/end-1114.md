# A.苹果与肉桂（Apple and Cinnamon）
## 题目详情
Alice 有一个不透明的布袋，里面装着苹果味和肉桂味两种糖珠。袋中至少有 $X$ 颗苹果味糖珠和 $Y$ 颗肉桂味糖珠。Alice 从袋中随机抽取两颗糖珠，每次等概率地抽取一颗，抽出后不放回。她希望两种口味各抽到一颗。在所有满足数量要求的装袋方案中，两颗糖珠口味相同的概率最小是多少？
**input**
输入仅一行，包含两个整数 $X$ 和 $Y$（$1 \le X, Y \le 10^9$），分别表示袋中苹果味和肉桂味糖珠的数量下限。
**output**
输出一个实数，表示抽到两颗相同口味糖珠的最小概率。
若你的答案与正确答案的绝对误差或相对误差不超过 $10^{-9}$，则视为正确。

[我]认为是否 $f(a,b)$ 会在距离 $(a,b)$ 最近距离一点时最小，而后越大  
[我]否定了[白]的暴力想法，因为没有明确终止点，故无法直接暴力  
同时[我]否定了我的概率二分做法，不一定可行且原因如上  
[白]猜测 $(x+1,y),(x,y+1),(x,y)$ 三种方法  
[孙]以[白]的 $(max(x,y),max(x,y)-1)$ 方法写出下列方法提交并AC:
```cpp
int main() {
    ios;
    ll x,y;
    double num;
    ll a=max(x,y);
    ll b=a-1;
```

Bobo 正在玩一个格点构造的游戏。他的初始集合为 $S = \{(0, 0), (A, 0), (0, B), (A, B)\}$，其中每个元素都是一个格点，即横、纵坐标均为整数的点。Bobo 的目标是生成一个特定的格点 $(X, Y)$。
为了实现目标，Bobo 可以通过以下操作来扩展集合 $S$：
* 选择集合 $S$ 中的两个格点 $P$ 和 $Q$，并在满足 $\frac{P + Q}{2}$ 也是一个格点的情况下，将 $\frac{P + Q}{2}$ 加入 $S$。
现在，Bobo 想找到一种操作次数最少的方案，以使得集合 $S$ 中包含点 $(X, Y)$，或说明该目标不可能达成。

**output**

否则，在第一行中输出一个整数 $k$（$0 \le k \le 10^5$），表示达到目标所需的最少操作次数。接着输出 $k$ 行，描述一种最优方案。其中第 $i$ 行包含四个整数 $U_i, V_i, S_i, T_i$（$0 \le U_i, V_i, S_i, T_i \le 10^9$），描述在第 $i$ 次操作中选择的格点 $P = (U_i, V_i)$ 和 $Q = (S_i, T_i)$。

# C.游标寻最小值（Game: Cursor Minimum）
## 题目详情
**本题是一道交互题。**
交互器隐藏了一个长度为 $n$ 的排列 $p_1, p_2, \dots, p_n$，你需要找出排列中最小值的下标。**排列在交互开始前就已确定，且在整个交互过程中保持不变。**
每次询问时，你只能给出一个下标。如果上一次询问的下标是 $i$，本次询问的下标是 $j$，交互器会告诉你 $p_i$ 和 $p_j$ 的大小关系。
正式评测共有 $100$ 个测试文件，你的程序将在每个文件上独立运行一次。每次运行时，$n = 30\,000$，最多可以询问 $q_{\max} = 42\,000$ 次。
**交互说明**
交互开始时，先读入两个整数 $n$ 和 $q_{\max}$，分别表示排列的长度和询问次数上限。
在每次合法询问后，交互器会返回一个字符串，其内容为 `<`、`>` 或 `=`，具体规则如下：
* 首次询问时，返回 `=`。
* 此后，设上一次询问的下标为 $i$。若 $p_i < p_j$，返回 `<`；若 $p_i > p_j$，返回 `>`；若 $p_i = p_j$，返回 `=`。由于 $p$ 是排列，只有连续两次询问同一下标时才会出现最后一种情况。
确定答案后，输出一行 `! a`，其中 $a$ 是你认为最小值所在的下标，随后结束程序。**提交最终答案不计入询问次数。**
每次输出询问或最终答案后都要刷新输出缓冲区。使用 C++ 时，可以用 `endl` 换行并刷新，也可以在换行后调用 `cout.flush()`。
如果询问次数超过 $q_{\max}$，询问的下标越界、输出的命令不合法或提交的答案错误，将被判为答案错误（Wrong Answer）。
**simple**
样例仅用于演示交互过程。隐藏排列为 $p = (3, 1, 4, 2)$。下表按时间先后列出交互过程，每行表示一方输出的一行内容。
| 选手程序 | 交互程序 | 说明 |
| --- | --- | --- |
|  | `4 5` | 初始参数 $n, q_{\max}$ |
| `? 1` |  | 第 $1$ 次询问 |
|  | `=` | 首次询问，返回 `=` |
| `? 2` |  | 第 $2$ 次询问 |
|  | `>` | $p_1 = 3 > p_2 = 1$ |
| `? 4` |  | 第 $3$ 次询问 |
|  | `<` | $p_2 = 1 < p_4 = 2$ |
| `! 2` |  | 提交最小值的下标 |
**note**
首次询问得到 `=`。接着询问下标 $2$ 时，比较的是 $p_1 = 3$ 与 $p_2 = 1$，因此返回 `>`。再询问下标 $4$ 时，比较的是 $p_2 = 1$ 与 $p_4 = 2$，因此返回 `<`。最小值位于下标 $2$，所以 `! 2` 是正确答案。
题目附件提供了本地交互工具 `local_interactive.py`。使用参数 `--perm 3,1,4,2 --limit 5` 可以复现样例的评测环境。通过本地测试不代表能通过正式评测。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define ios ios::sync_with_stdio(false);cin.tie(0);
typedef long long ll;

int main() {
    ios;
    int n, q; cin >> n >> q;
    vector<bool> vis(n + 1, 0);
    vector<int> sz;
    for (int i = 2; i <= n; i++) sz.push_back(i);
    cout << "? " << 1 << endl;
    char temp; cin >> temp;
    int last = 1;
    while (sz.size() > 1) {
        int t = sz.back(); sz.pop_back();
        if (vis[t] || last == t) continue;
        cout << "? " << t << endl;
        char c; cin >> c;
        if (c == '>') vis[last] = 1, sz.push_back(t);
        else if (c == '<') vis[t] = 1, sz.push_back(last);
        last = t;
    }
    cout << "! " << sz[0];
    return 0;
}
```

# D.别带着怒意回首（Don't Look Back in Anger）
## 题目详情
Alice 有 $k$ 段珍贵的回忆。她按时间先后为这些回忆赋予从 $1$ 到 $k$ 的幸福值。她还写下了 $n$ 道咒语，第 $i$ 道咒语用一个排列 $A_i$ 来重排回忆。施放一段连续的咒语之后，有些较晚的回忆会排到较早的回忆之前。Alice 将这样的一对回忆称为一对遗憾。她想知道，对每一段非空的连续咒语分别统计遗憾的对数，它们的总和是多少？
形式化来说，每个 $A_i$ 都是 $\{1, 2, \dots, k\}$ 的一个排列。对于两个排列 $p$ 和 $q$，其复合 $p \circ q$ 定义为 $(p \circ q)(x) = p(q(x))$。对于 $1 \le l \le r \le n$，第 $l$ 至第 $r$ 道咒语对应的排列为
$$P_{l, r} = A_l \circ A_{l+1} \circ \dots \circ A_r.$$
排列的复合满足结合律，括号的位置不影响结果，但各排列的先后顺序固定如上。
记 $\text{inv}(p)$ 为排列 $p$ 的逆序对数，即满足 $1 \le x < y \le k$ 且 $p(x) > p(y)$ 的数对 $(x, y)$ 的个数。
你需要求出：
$$\sum_{1 \le l \le r \le n} \text{inv}(P_{l, r}).$$
**input**
第一行包含两个整数 $n$ 和 $k$（$1 \le n, k \le 10^5$，$nk \le 10^5$）。
接下来 $n$ 行，每行包含 $k$ 个整数。第 $i$ 行给出排列 $A_i(1), A_i(2), \dots, A_i(k)$。
**output**
输出一行，包含一个整数，表示所有非空连续段对应的排列的逆序对数之和。
