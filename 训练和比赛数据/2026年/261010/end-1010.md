# 2271B.MEX Game
[Tag]博弈论
## 题目详情
For a multiset $\mathcal{S}$ and a positive integer $k$, let $\operatorname{mex}_k(\mathcal{S})$ be the smallest non-negative integer that appears in $\mathcal{S}$ fewer than $k$ times. In particular, $\operatorname{mex}_1(\mathcal{S})$ is the usual $\operatorname{mex}$$^{\text{∗}}$ of $\mathcal{S}$.
For example:
-   $\operatorname{mex}_1(\{0, 1, 1, 2\}) = 3$;
-   $\operatorname{mex}_2(\{0, 0, 1, 1, 1, 3\}) = 2$;
-   $\operatorname{mex}_2(\{0, 1, 1, 2\}) = 0$;
-   $\operatorname{mex}_2(\{0, 0, 1, 2\}) = 1$.
You are given an **even** integer $n$, a positive integer $k$, and $n$ cards. The integer $a_i$ is written on the $i$\-th card.
Alice and Bob play the following game with these cards. Alice moves first, and the players alternate turns. On each turn, the current player takes any one of the remaining cards. The game ends when all $n$ cards have been taken, so each player ends up with exactly $\dfrac{n}{2}$ cards.
Let $\mathcal{A}$ be the multiset of integers written on Alice's cards, and let $\mathcal{B}$ be the multiset of integers written on Bob's cards. Alice wins if $\operatorname{mex}_k(\mathcal{A}) \ne \operatorname{mex}_k(\mathcal{B})$, and Bob wins otherwise.
Determine whether Alice wins if both players play optimally.
$^{\text{∗}}$The minimum excluded (MEX) of a collection of integers $c_1, c_2, \ldots, c_m$ is defined as the smallest non-negative integer $x$ which does not occur in the collection $c$.
**Input**
Each test contains multiple test cases. The first line contains the number of test cases $t$ ($1 \le t \le 10^4$). The description of the test cases follows.
The first line of each test case contains two integers $n$ and $k$ ($2 \le n \le 2 \cdot 10^5$, $n$ is **even**, $1 \le k \le n$) — the number of cards and the parameter of the game.
The second line of each test case contains $n$ integers $a_1, a_2, \ldots, a_n$ ($0 \le a_i \le n$) — the integers written on the cards.
It is guaranteed that the sum of $n$ over all test cases does not exceed $2 \cdot 10^5$.
**Output**
For each test case, output "YES" if Alice wins, and "NO" otherwise.
You can output the answer in any case (upper or lower). For example, the strings "yEs", "yes", "Yes", and "YES" will be recognized as positive responses.
